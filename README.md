# DataFeel Community Projects

Projects built with the [DataFeel Dev Kit](https://datafeel.com) by students, researchers, and makers at hackathons and beyond.

Each DataFeel Dot produces vibration, heat and cold, and light, and includes motion sensing. These projects show what people build when touch becomes an output.

> These are community projects, maintained by their own teams. Code links point to the original repositories. For official sample code and documentation, see the DataFeel quick-start materials.

## Add your project

1. Add the topic **`datafeel`** to your repository (on your repo page, click the gear next to **About**, then add it under **Topics**). Tagged repos appear in the list below automatically within a week.
2. Want a full entry with your team, demo video, and description? [Submit your project](../../issues/new?template=submit-project.yml) and we'll add it.

See [CONTRIBUTING.md](CONTRIBUTING.md) for details.
